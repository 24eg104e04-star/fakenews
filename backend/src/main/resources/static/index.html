How The System Works

Three streamlined steps to analyze news authenticity using our rule-based scoring architecture.

1. Input News Article

Paste or type any news excerpt or headline into the detection console.

2. Heuristic Analysis

The Spring Boot backend scans for clickbait keywords, punctuation anomalies, and source citations.

3. Instant Verdict & History

Receive an immediate REAL/FAKE verdict with confidence score and record it permanently in MySQL.

Capabilities

Key Project Features

User Authentication

Secure registration and login with BCrypt password hashing, session persistence, and protected routes.

Rule Heuristic Engine

Detects sensational phrases ("miracle", "shocking", "you won't believe"), capitalization ratio, and emotional punctuation.

MySQL Persistence

Every article, detection verdict, confidence percentage, and timestamp is stored via Spring Data JPA.

Real-Time Stats

Interactive dashboard computing total checked articles, fake detections, and real news distribution dynamically.
